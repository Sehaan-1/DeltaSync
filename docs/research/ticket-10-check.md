## 1. Check Criteria & Verification Matrix

1. **Spec §10 Check 1 (Shift Invariance Test):**
   - Generated a 5 MB pseudo-random byte payload (68 FastCDC chunks).
   - Prepended 100 random bytes to create a modified stream (68 FastCDC chunks).
   - Chunked and SHA-256 fingerprinted both streams using `ChunkFingerprinter`.
   - **Measured:** **67 / 68 chunks matched (98.53%)**, surpassing the mandatory $>95\%$ threshold.
   - **Delta Transfer Result:** Reused 5,156,568 bytes (**98.35%** reuse ratio), transferring only 86,412 bytes across the network.
2. **Known-Answer Vector Test:**
   - 1 MB deterministic buffer generated by repeating `"DeltaSync-FastCDC-Verification-String-0123456789\n"`.
   - Verified strict determinism across independent runs, contiguous offsets, strictly monotonic chunk indices, and whole-file SHA-256 root hash equivalence.
3. **Spec §10 Check 3 (In-Place Edit Delta Test):**
   - Modified 5 bytes in a 1 MB file at offset 500,000.
   - Verified `ManifestDiff` isolated exactly 1 missing chunk ($\le 64$ KB transferred, $>90\%$ reuse).
4. **Empty and Micro-file Verification:**
   - 0-byte buffer produces 0 chunks and canonical empty SHA-256 root hash (`e3b0c44298fc1c149afbf4c8996fb92427ae41e4649b934ca495991b7852b855`).
   - Micro-files (1 byte, 500 bytes, 16,383 bytes) produce exactly 1 chunk whose hash equals the whole-file root hash.
5. **Contract Invariants & Structural Validation:**
   - Monotonic indices and contiguous offsets enforced by `FileManifest` constructor.
   - Value equality and structural hashing verified for `ChunkDescriptor`, `FileManifest`, and `ManifestDiff`.
6. **Intentional Fault Injection Proof:**
   - Corrupted chunk hash computation (`hash[0] ^= 0xFF`) in `ChunkFingerprinter.cs`.
   - Verified tests failed immediately:
     `Expected manifest.RootHash to be "11feb0a3...", but "eefeb0a3..." differs near "eef" (index 0).`
   - Restored original implementation and confirmed all 80 tests pass.
